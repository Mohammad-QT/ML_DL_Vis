| Lesson Learn, Play, Check | Advance to Play, Check or Code | Ink forward button beside a ghost Back button. Quiz answers are lightly outlined tiles. |

| Next lesson | Go to the next lesson or return to the course route | Linked card with a custom yellow arrow badge. |

| Model selection · boosting | Advance to the next round | Filled Next, with Prev, Play and New data styled as neutral chips. |
| Metrics, regularization, association rules and multiple regression | Adjust thresholds, parameters or data choices | Sliders, selects, choice chips or checkboxes update results live. |
