title: Naive Bayes
lede: Learn what a typical point of each class looks like, then ask which class a new point looks more like.
figure: { preset: circles, seed: 12, cell: 4, dot: 3.6, tint: 0.24 }
steps:
  - For each class, learn the average and the spread of every feature.
  - For a new point, work out how likely it is under each class, one feature at a time.
  - Multiply those chances together (the “naive” part), and weigh by how common each class is.
  - The class with the higher score wins.

Naive Bayes asks a simple question: <mark>which class does this point look like more?</mark> It learns the typical value and the spread of each feature in each class, and picks the class that explains the new point best. It is fast and needs very little data.
