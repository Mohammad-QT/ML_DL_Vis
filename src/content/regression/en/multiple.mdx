Real answers rarely depend on one thing. A startup's profit depends on how much it spends on research, on marketing, and maybe where it is based. <mark>Multiple linear regression</mark> gives every input its own weight and adds the pieces up.

You cannot draw this on a flat board, because every input needs its own axis. So instead of a line, you read the <b>weights</b>: each one says how much the prediction moves when that input goes up by one, with the others held fixed.
