A straight line cannot follow a curve. <mark>Polynomial regression</mark> fixes that with a small trick: it adds columns for x², x³ and so on, then runs the same linear regression on all of them. The result is a smooth curve whose number of bends is set by the <b>degree</b>.

The degree is the one setting to tune. Too low, and the curve misses the pattern. Too high, and it bends to follow noise.
