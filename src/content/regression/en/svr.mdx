Support vector regression tolerates small mistakes. You choose a tube of width <b>epsilon</b> around the curve. A training point inside the tube costs nothing, so the curve is not tugged by every little wobble. Only the points outside the tube pull on it.

With the RBF kernel, the curve can bend as much as the data needs, so SVR handles curves that a straight line cannot. Like every distance-based model, it needs <mark>feature scaling</mark> first.
