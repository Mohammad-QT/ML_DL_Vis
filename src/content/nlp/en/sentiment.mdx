code: |
  import pandas as pd
  from sklearn.feature_extraction.text import CountVectorizer
  from sklearn.model_selection import train_test_split
  from sklearn.naive_bayes import MultinomialNB
  
  url = "https://raw.githubusercontent.com/Mohammad-QT/ML_DL_Vis/main/datasets/cafe_reviews.csv"
  reviews = pd.read_csv(url)
  train, test = train_test_split(
      reviews, test_size=0.25, stratify=reviews.liked, random_state=42
  )
  vectorizer = CountVectorizer(max_features=120)
  X_train = vectorizer.fit_transform(train.review)
  X_test = vectorizer.transform(test.review)
  model = MultinomialNB(alpha=1).fit(X_train, train.liked)
  print(model.score(X_test, test.liked))

In Part 3, Naive Bayes predicts a class from features. Here those features are counts, so we use <mark>multinomial Naive Bayes</mark>. It learns which words are more typical of each class. A word like “smooth” may push toward “liked it”; “burnt” may push the other way.

Each repeated word adds the same push again. The number on a chip is a <mark>log-likelihood ratio</mark>: a positive value favors “liked it”; a negative value favors “didn’t like it”. The model also starts with a small bias if one class is more common in training. Adding one to each word tally is called <mark>Laplace smoothing</mark>.
