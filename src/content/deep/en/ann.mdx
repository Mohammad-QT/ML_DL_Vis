code: |
  from sklearn.datasets import make_circles
  from sklearn.model_selection import train_test_split
  from sklearn.neural_network import MLPClassifier
  from sklearn.pipeline import Pipeline
  from sklearn.preprocessing import StandardScaler

  X, y = make_circles(n_samples=400, factor=0.35, noise=0.08, random_state=42)
  X_train, X_test, y_train, y_test = train_test_split(
      X, y, test_size=0.25, stratify=y, random_state=42
  )
  model = Pipeline([
      ("scale", StandardScaler()),
      ("mlp", MLPClassifier(hidden_layer_sizes=(8, 8), activation="relu", max_iter=1000, random_state=42)),
  ])
  model.fit(X_train, y_train)
  print(model.score(X_test, y_test))

A single <mark>neuron</mark> looks like logistic regression: it multiplies each input by a weight, adds a bias and passes the sum through an activation function. Stack several units into a hidden layer, feed their outputs into the next layer, and end with an output unit that turns its score into P(class B). In the network diagram, blue lines are positive weights, pink lines are negative weights, and thicker lines carry stronger weights.

The <mark>activation function</mark> (ReLU or tanh) is what lets the boundary bend. Without that non-linear bend, stacking layers would still collapse into one straight line. With it, hidden units combine simple cuts into curves that can wrap around circles or trace a spiral.

<mark>Sigmoid</mark> squashes any number into 0–1 and is what the output unit uses to give P(class B), while softmax extends the same idea to many classes in the CNN lesson. For hidden layers, tanh squashes into −1 to 1 and stays centered on zero. <mark>ReLU</mark> keeps positive values and turns negatives into 0, which trains fast, though a unit can get stuck at 0 ("die"). Leaky ReLU keeps a small slope (0.1) for negatives so units never fully die.

Training repeats a simple loop over small mini-batches of points. A forward pass produces predictions and measures <mark>cross-entropy loss</mark>. <mark>Backpropagation</mark> then works backward to find how each weight contributed to the error, and gradient descent nudges every weight downhill. About a quarter of the points are held out with rings as a test set so you can check whether the network generalizes.
