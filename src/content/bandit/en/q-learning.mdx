code: |
  import numpy as np
  from sklearn.metrics import mean_absolute_error

  grid = ["......", ".##.X.", "...#..", ".X.#..", "..#...", "S....G"]
  moves = [(-1, 0), (0, 1), (1, 0), (0, -1)]
  rng = np.random.default_rng(2026)
  q = np.zeros((6, 6, 4))
  steps, goal_steps = [], []

  for episode in range(400):
      row, col = 5, 0
      for count in range(1, 73):
          values = q[row, col]
          best = np.flatnonzero(values == values.max())
          action = rng.integers(4) if rng.random() < .2 else rng.choice(best)
          dr, dc = moves[action]
          nr, nc = row + dr, col + dc
          if not (0 <= nr < 6 and 0 <= nc < 6) or grid[nr][nc] == "#":
              nr, nc = row, col
          tile = grid[nr][nc]
          reward = {"G": 1, "X": -1}.get(tile, -.04)
          terminal = tile in "GX"
          future = 0 if terminal else q[nr, nc].max()
          q[row, col, action] += .5 * (reward + .95 * future - values[action])
          row, col = nr, nc
          if terminal:
              break
      steps.append(count)
      if tile == "G":
          goal_steps.append(count)

  recent = goal_steps[-30:]
  print(mean_absolute_error([5] * len(recent), recent))
---
A bandit choice ends with a reward. A move in a grid also changes where the agent will be next. The agent may spend several moves going around a wall before it gets the reward at the goal.

Q-learning keeps a <mark>score for every cell and move</mark>. It updates one score at a time: it nudges the score toward the reward it just got plus the best score it sees ahead. The learning rate controls the size of that nudge. The discount controls how much future rewards count. Reaching a pit or the goal ends the episode, so there is no future score to add.
