**This site** teaches machine learning by letting you watch models decide. Add a point, move a slider, and see the line move. Every lesson has four tabs: <b>Learn</b> (the idea), <b>Play</b> (a live board), <b>Check</b> (a short quiz) and <b>Code</b> (the Python that does it).

<h3 class="display">What Colab is</h3>

**Colab** is Google's free notebook in your browser. It runs Python on Google's computers, so you install nothing. Each Code tab has an **Open in Colab** button. It opens a copy of our notebook, straight from GitHub.

Sign in with a Google account, press <code>Shift + Enter</code> to run a cell, and change anything you like. You can't break the original. Your changes are <mark>not saved</mark> unless you save them: use **File → Save a copy in Drive** to keep the notebook, or **File → Download → .ipynb** to keep a file.

Go in order. Part 1 prepares the data in four short lessons. Then pick Regression or Classification. Not sure which algorithm fits? The picker on the home page asks three questions.
