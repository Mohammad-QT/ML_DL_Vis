If you test a model on the same points it learned from, it can simply remember them and look perfect. So before training, set aside a share of the rows as the <mark>test set</mark>. The rest is the **training set**. On every board in this course, the ringed points are the test set.

How big should it be? 20 to 30 per cent for testing is common. Less test data makes the score noisy. Less training data makes the model worse.

The split is random. <code>random_state</code> is the seed of that randomness: the same number gives the same split every time, so you tomorrow, or a friend today, get the same result. Change the number and you get a different split, and a slightly different score.
