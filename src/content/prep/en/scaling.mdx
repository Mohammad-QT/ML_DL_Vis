  sc = StandardScaler()
  X_train = sc.fit_transform(X_train)   # learn mean and spread from training rows
  X_test = sc.transform(X_test)         # reuse the same numbers on the test rows
---
K-NN and SVM measure **distance** between points. If one feature has much bigger numbers, it dominates the distance and the other feature hardly counts. A salary gap of 10,000 swamps an age gap of 30 years.

<mark>Standardising</mark> fixes this. For each column, subtract its mean and divide by its spread. Every column ends up centred on 0 with a spread of 1, so each feature gets a fair say.

Which models need it? Anything built on distances or on gradient steps: K-NN, SVM, kernel SVM and logistic regression. Decision trees and random forests don't, because they only ask whether a value is above a number.
