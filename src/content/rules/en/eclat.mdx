code: |
  baskets = [['pasta', 'sauce'], ['pasta'], ['pasta', 'sauce'], ['cheese']]
  tids = {}
  for basket_id, basket in enumerate(baskets, start=1):
      for item in basket:
          tids.setdefault(item, set()).add(basket_id)

  shared = tids['pasta'] & tids['sauce']
  print(sorted(shared), len(shared) / len(baskets))
---
Instead of storing a list of **items in each basket**, Eclat stores a list of **basket IDs for each item**. These are called <mark>transaction ID lists</mark>, or tid-lists. To count baskets with both pasta and sauce, keep only the IDs that appear in both lists. This is their intersection.

With the same minimum support, Eclat finds the same frequent groups as Apriori. Eclat can be faster when repeated passes over the baskets are expensive and the ID lists are small enough to intersect quickly. Long lists can take more memory and more work to intersect.
