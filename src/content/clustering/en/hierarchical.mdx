code: |
  import pandas as pd
  from sklearn.cluster import AgglomerativeClustering

  url = "https://raw.githubusercontent.com/Mohammad-QT/ML_DL_Vis/main/datasets/clustering_points.csv"
  X = pd.read_csv(url)[["x", "y"]]
  model = AgglomerativeClustering(n_clusters=3, linkage="ward")
  groups = model.fit_predict(X)
  print(groups)
---
K-Means asks for K first. **Agglomerative** clustering builds the full merge tree first, then lets you decide how many groups to keep. The tree is called a <mark>dendrogram</mark>. Each tip at the bottom is one point, and each horizontal join records a merge.

Ward linkage favours compact groups. At each step, it measures how much the merge would increase the sum of squared distances from points to their own group centres. It picks the cheapest merge, not necessarily the two centres that are closest to each other.
