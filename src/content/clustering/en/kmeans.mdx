code: |
  import pandas as pd
  from sklearn.cluster import KMeans

  url = "https://raw.githubusercontent.com/Mohammad-QT/ML_DL_Vis/main/datasets/clustering_points.csv"
  X = pd.read_csv(url)[["x", "y"]]
  model = KMeans(n_clusters=3, init="k-means++", n_init=10, random_state=42)
  groups = model.fit_predict(X)
  print(model.cluster_centers_, model.inertia_)
---
When your points have no labels, you can still ask which ones belong together. K-Means draws groups around <mark>centres</mark>. It does not know what any group means; it uses only the distances between points and centres.

The elbow chart shows **WCSS**, the within-cluster sum of squares: square each point's distance to its nearest centre, then add those squares. The chart tries several starts for each K and keeps the lowest score it finds. Use the bend as a clue, not as proof that you have found the right number of groups.
